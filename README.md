# Анализ 100 самых популярных фильмов Киноафиши

В проект включён интерактивный отчёт Power BI по фильмам. В нём представлены количество фильмов и средний рейтинг, распределение по странам, годам и жанрам, а также таблица фильмов с рейтингами.

Файл отчёта: `kinoafisha_studyproject.pbix`

Чтобы открыть отчёт, скачайте файл и запустите его в Power BI Desktop. Данные и визуализации доступны для изучения внутри отчёта.
